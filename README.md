# Movie Recommendation System

A full-stack movie recommendation application built with
React and Python.

## Tech Stack

### Frontend
- React
- Vite
- Axios

### Backend
- Python
- FastAPI
- Pandas
- NumPy
- Scikit-learn

## Features

- Browse movies
- Search movies
- Get personalized recommendations
- Content-based filtering
- Collaborative filtering

## Project Structure

- frontend/ - React application
- backend/ - Python API and recommendation engine
